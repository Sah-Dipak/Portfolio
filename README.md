# Static Portfolio

This folder contains a static HTML/CSS/JavaScript portfolio that does not require a backend.

## How to use

1. Open `portfolio/index.html` in a browser.
2. Or serve the folder with a local static server (optional):
   - `npx http-server` or `python -m http.server`
3. The contact form is purely client-side and displays a confirmation message.

## Files

- `index.html` — main portfolio page
- `styles.css` — layout and visual styling
- `script.js` — form validation and interaction
